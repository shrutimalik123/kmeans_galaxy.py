# 🌌 k-Means Galaxy: Unsupervised Clustering Sim

An interactive Machine Learning simulation designed to teach the fundamentals of **Unsupervised Learning**. You play as a Cosmic Commander tasked with grouping unidentified space objects into distinct categories. Unlike Supervised Learning, you have no labels—you must rely on the **k-Means Clustering** algorithm to find hidden patterns in the data[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span).

## 🎓 Learning Objectives

This project focuses on teaching:
* **Unsupervised Learning:** Discovering patterns and structures in unlabeled data without a "correct" answer to guide the process[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).
* **Centroids:** Understanding the role of cluster "center points" that start randomly and move to represent the average of assigned data points[span_4](start_span)[span_4](end_span).
* **Euclidean Distance:** The mathematical method used to assign data points to the nearest cluster center[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
* **Hyperparameter k:** Learning how the number of clusters (k) affects the interpretation of the results.
* **Convergence:** The point at which centroids stop moving, indicating that the algorithm has found stable groups[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).

## ✨ Features

* **Astronomy Scenario:** Makes abstract clustering concepts intuitive by grouping "Stars," "Planets," and "Nebulae."
* **Centroid Drift:** Visualizes how cluster centers move toward the mean of their assigned data points during the training process.
* **Exploratory Analysis:** Encourages experimentation with different 'k' values to find the most meaningful groups.
* **Minimalist Logic:** Built in pure Python 3 with no external library requirements.
